# Nagar Shield 360 — Flutter অ্যাপ

এটি বাংলা ভাষার একটি প্রাথমিক Flutter অ্যাপ। ব্র্যান্ডেড লোডার স্ক্রিনের পর নগর পর্যবেক্ষণ, কাজের ধাপ ও প্রস্তাবিত পাইলট নিয়ে মূলপাতা দেখা যায়। মানচিত্রটি নমুনা; এখনো কোনো লাইভ ডেটা সংযোগ নেই।

## চালু করুন

    flutter pub get
    flutter run

এই ফোল্ডারই Flutter প্রজেক্টের মূল ডিরেক্টরি। অ্যাপের স্ক্রিনগুলো `lib/` ফোল্ডারে আছে।
