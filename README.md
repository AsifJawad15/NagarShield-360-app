# Nagar Shield 360 মূলপাতা

এটি Next.js দিয়ে তৈরি একটি বাংলা React মূলপাতা। মানচিত্র ও পর্যবেক্ষণের তথ্য কেবল নমুনা হিসেবে দেখানো হয়েছে।

## নিজের কম্পিউটারে চালু করুন

```sh
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) ঠিকানায় দেখুন।

প্রোডাকশন বিল্ড তৈরি করতে:

```sh
npm run build
```
